# Supermarket

Sistema de gestión de ventas e inventario para un micromercado.

Este repositorio contiene los dos componentes del proyecto:

- `supermarket/`: aplicación web y API REST desarrollada con Laravel, MySQL, Bootstrap y Vite.
- `app-movil-supermarket/`: aplicación móvil desarrollada con React Native y Expo que consume la API del sistema web.

## Requisitos

- PHP y Composer.
- MySQL o MariaDB.
- Node.js y npm.
- Laravel.
- Expo Go o un emulador compatible para ejecutar la aplicación móvil.

## Instalación

Cada componente cuenta con su propio README, donde se detallan las instrucciones de instalación, configuración y ejecución.

### Aplicación web y API

Consulta `supermarket/README.md` para configurar el entorno de Laravel, la conexión con MySQL y los servicios de la API.

### Aplicación móvil

Consulta `app-movil-supermarket/README.md` para instalar las dependencias, configurar la conexión con la API y ejecutar la aplicación con Expo.

## Objetivo del proyecto

Facilitar la gestión de ventas e inventario de un micromercado mediante una aplicación web y una aplicación móvil integradas.
