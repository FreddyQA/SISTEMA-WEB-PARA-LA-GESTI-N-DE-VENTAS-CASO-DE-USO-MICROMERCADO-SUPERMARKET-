# Supermarket

Sistema de gestión de ventas e inventario para un micromercado.

Este repositorio reúne los dos componentes del proyecto:

- `supermarket/` — aplicación web y API REST (Laravel + MySQL + Vite).
- `app-movil-supermarket/` — aplicación móvil (React Native / Expo) que consume la API.

Cada carpeta tiene su propio README con las instrucciones de instalación.
